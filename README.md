# DevKit Student Hub

A free, fast browser toolkit for software engineering students.

## Features

- JSON formatter and validator
- HEX and RGB color tool
- PX, REM, KB, MB and GB converter
- Quick notes saved with localStorage
- Developer resource links
- Dark and light mode
- Responsive layout
- No login
- No database
- No paid APIs

## Tech

HTML, CSS and JavaScript.

## Run locally

Open `index.html` in a browser.

## GitHub Pages

1. Open repository Settings.
2. Select Pages.
3. Choose Deploy from a branch.
4. Select `main` and `/root`.
5. Save.

Your site will be available through your GitHub Pages URL.
